景深合成相机 v2 - 使用说明
====================================

【v2 改进】
1. 拍摄分辨率约 1200 万像素（4:3），不再固定 400 万
2. 每个对焦位置等镜头到位后再拍，减少对焦不准导致的模糊
3. 合成改为逐张流式处理（拍完一张立刻开始算，与后续拍摄并行），只保留一张原图在内存中，降低闪退风险，并开启 largeHeap；合成核心按行分块多线程并行，速度更快
4. 切到后台时自动释放相机，回到前台自动重开
5. 预览按传感器方向和屏幕旋转修正，不再变形
6. 保存兼容 Android 9 及以下（需要存储权限）

【重要说明】
合成输出为约 300 万像素（2000x1500），这是为了在手机上稳定运行做的取舍。
要输出 1200 万像素的完整结果，需要分块合成，属于 v3 的内容。

【安装】
与 v1 相同：用 Android Studio 打开文件夹 -> 连接手机 -> 点运行。

【使用】
1. 手机用支架或靠稳，拍摄过程中不能动
2. 点"拍摄合成"，App 会依次拍 7 张不同焦点的照片
3. 合成完成后点"保存到相册"

【已知限制】
1. 仍未做图像对齐，手持会有重影
2. 合成采用"最大清晰度选择"，边缘可能有轻微接缝，可通过调大 SMOOTH_RADIUS 缓解
3. 本版本仅完成代码编写，尚未在真机上验证，请以实际运行结果为准
